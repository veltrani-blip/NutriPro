# NutriPro — direção visual inicial

## Ideia
**Clareza clínica sem aparência hospitalar.** O produto deve parecer confiável, humano e preciso.

## Marca
O símbolo combina um “N” contínuo com uma curva que lembra evolução. A folha pequena funciona como detalhe secundário, não como clichê central da identidade.

## Tokens iniciais
- Verde principal: `#167451`
- Verde profundo: `#0B5038`
- Verde suave: `#E6F5EE`
- Texto: `#10251D`
- Fundo: `#F6F9F7`
- Divisórias: `#DFE9E3`

## Linguagem de interface
- números importantes grandes e objetivos;
- alertas clínicos destacados sem linguagem julgadora;
- cartões apenas quando agrupam informação útil;
- formulários divididos por contexto, não por quantidade arbitrária de campos;
- nenhum gráfico sem pergunta operacional clara.
